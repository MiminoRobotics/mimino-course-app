## Updating the current-state screenshot

As the application grows, replace `current-state.png` with a newer screenshot using **the same
filename** — the README picks it up with no edit. If the newer shot shows something different, update
the caption under it in `README.md` so the two still agree.

Screenshots look best at 16:9. The app window can be sized to 1600 × 900 before capturing.

## Adding more pictures later

The README deliberately carries one screenshot right now, because most of the product is still being
built and a wall of half-finished screens would oversell it. Good candidates to add as they become
real:

- The Connect screen with a board detected.
- The motor-test safety checklist — the clearest proof the product takes safety seriously.
- The receiver screen with the sticks moving.
- The flight simulator in flight, ideally as a short animated GIF.
- A photo of a student's finished quadcopter next to the app.

To add one, drop the file here and add an image line plus a caption in the matching README section.
