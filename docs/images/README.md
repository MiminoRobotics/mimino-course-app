# Images

Every file here except `brand-lockup.png` is a **placeholder**. The main `README.md` already points
at these filenames, so adding a real picture means replacing a file — no editing of the README.

## How to add a real screenshot

1. Take the screenshot (1600 × 900 or any 16:9 size looks best).
2. Save it over the placeholder, keeping **exactly the same filename**.
3. Commit. The README picks it up automatically.
